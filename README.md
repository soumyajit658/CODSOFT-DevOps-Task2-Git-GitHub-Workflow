# CODSOFT DevOps Internship — Task 2

## Git & GitHub Workflow

This project was created as part of the **CODSOFT DevOps Internship – Task 2**.

The objective of this task is to practice Git and GitHub workflows, including repository management, commits, branches, pull requests, code collaboration, merge conflict resolution, and branch protection.

---

## 📌 Task Objective

The main objectives of this task were:

- Create and manage a Git repository
- Connect the local repository with GitHub
- Practice Git commits
- Create and work with branches
- Push branches to GitHub
- Create and merge Pull Requests
- Demonstrate a GitHub collaboration workflow
- Create and resolve a merge conflict
- Maintain a clean Git history
- Configure branch protection rules for the `main` branch

---

## 🛠️ Technologies & Tools

- **Git**
- **GitHub**
- **Git Bash / PowerShell**
- **GitHub Pull Requests**
- **GitHub Branch Rulesets**
