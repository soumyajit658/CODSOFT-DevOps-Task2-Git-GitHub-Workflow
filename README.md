# CODSOFT DevOps Task 2 - Git & GitHub Workflow

## 📌 Overview

This project is part of the **CODSOFT DevOps Internship - Task 2**.

The purpose of this task is to demonstrate a practical **Git and GitHub collaboration workflow**, including repository creation, commits, branching, pull requests, code changes, merge conflicts, conflict resolution, and working with the main branch.

---

## 🎯 Objective

The main objectives of this task are:

- Create and initialize a Git repository
- Work with the `main` branch
- Create feature branches
- Make and track changes using Git
- Create commits with meaningful messages
- Push branches to GitHub
- Create and merge Pull Requests
- Demonstrate a merge conflict
- Resolve the merge conflict
- Understand Git history
- Configure protection/rules for the `main` branch
- Maintain a clean Git workflow
