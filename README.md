# CODSOFT DevOps Task 2 — Git & GitHub Workflow

## 📌 Overview

This project was completed as part of the **CODSOFT DevOps Internship – Task 2**.

The objective of this task is to understand and demonstrate a practical **Git and GitHub workflow**, including repository management, commits, branching, pull requests, code reviews, merge conflicts, and branch protection.

---

## 🎯 Objectives

- Create and manage a Git repository.
- Connect a local Git repository with GitHub.
- Practice Git commits and version control.
- Create and work with feature branches.
- Push branches to GitHub.
- Create and merge Pull Requests.
- Understand the code review workflow.
- Create and resolve merge conflicts.
- Maintain a clean and traceable commit history.
- Configure branch protection/rules for the `main` branch.

---

## 🛠️ Technologies Used

- **Git**
- **GitHub**
- **GitHub Pull Requests**
- **GitHub Branch Rulesets**
- **Windows PowerShell**
